# 🚀 Quick Start - Setup Trên 2 Máy

## ⚡ Setup Nhanh (5 phút)

### Bước 1: Lấy IP Address

**Trên mỗi máy, chạy:**

**Windows:**
```cmd
scripts\get-ip.bat
```

**Linux/macOS:**
```bash
chmod +x scripts/get-ip.sh
./scripts/get-ip.sh
```

**Ghi lại IP:**
- Máy A: `192.168.1.XXX`
- Máy B: `192.168.1.YYY`

### Bước 2: Tự động cấu hình

**Trên mỗi máy, chạy script setup:**

**Windows:**
```cmd
cd scripts
setup-network.bat
```

**Linux/macOS:**
```bash
cd scripts
chmod +x setup-network.sh
./setup-network.sh
```

**Chọn role:**
- `1` = Client (JavaFX)
- `2` = Origin Server
- `3` = P2P Tracker

### Bước 3: Chạy Services

#### Scenario: Windows (Origin) + Ubuntu (Client + Tracker)

**Máy A - Windows:**
```cmd
cd origin-server
mvn spring-boot:run
```

**Máy B - Ubuntu:**
```bash
# Terminal 1: Tracker
cd p2p-tracker
mvn spring-boot:run

# Terminal 2: Client
cd javafx-client
mvn javafx:run
```

#### Scenario: macOS (Client) + Ubuntu (Origin + Tracker)

**Máy A - macOS:**
```bash
cd javafx-client
mvn javafx:run
```

**Máy B - Ubuntu:**
```bash
# Terminal 1: Origin Server
cd origin-server
mvn spring-boot:run

# Terminal 2: P2P Tracker
cd p2p-tracker
mvn spring-boot:run
```

## ✅ Kiểm Tra

Sau khi chạy, kiểm tra logs:

1. **Client logs** sẽ hiển thị:
   ```
   [INFO] Local IP Address: 192.168.1.102
   [INFO] Tracker URL: http://192.168.1.100:8081
   [INFO] Origin Server URL: https://192.168.1.101:8443
   ```

2. **Origin Server logs** sẽ hiển thị:
   ```
   [ORIGIN] GET /manifest/100MB.zip | FROM: 192.168.1.102 → TO: Origin:8443
   ```

3. **Tracker logs** sẽ hiển thị:
   ```
   [TRACKER] POST /announce | FROM: 192.168.1.102 → TO: Tracker:8081
   ```

## 🔧 Nếu Script Không Chạy

### Cấu hình thủ công:

1. **Lấy IP của mỗi máy** (xem Bước 1)

2. **Sửa config files:**

**Client (`javafx-client/src/main/resources/config.properties`):**
```properties
tracker.url=http://IP_MÁY_TRACKER:8081
origin.server.url=https://IP_MÁY_ORIGIN:8443
```

**Origin Server (`origin-server/src/main/resources/config.properties`):**
```properties
server.host=IP_MÁY_ORIGIN
```

**Tracker (`p2p-tracker/src/main/resources/config.properties`):**
```properties
server.host=IP_MÁY_TRACKER
```

3. **Rebuild và chạy:**
```bash
mvn clean install
# Sau đó chạy services như Bước 3
```

## 🎯 Demo Flow

1. **Start Origin Server** → Logs hiển thị IP
2. **Start P2P Tracker** → Logs hiển thị IP  
3. **Start Client** → Tự động detect IP và connect
4. **Xem logs** → Thấy flow với IP addresses rõ ràng

## 💡 Tips

- **IP phải là IP thực** (192.168.x.x), không dùng localhost
- **Firewall** phải allow ports
- **Cùng network** (LAN) để demo P2P
- **Xem logs** để debug nếu có lỗi
